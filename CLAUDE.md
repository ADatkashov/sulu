## Продукт
SULU — Beauty Super App (маркетплейс). Три части: SULU Customer, SULU Business, SULU Admin.
Главный приоритет: сценарий клиента «найти услугу → салон и мастер → свободное время → запись → подтверждение».

## Стек (решение принято в первой сессии)
- `backend/` — Java 21, Spring Boot 3.5, PostgreSQL 16, Flyway, JdbcClient, JWT (Nimbus), OpenAPI.
- `web/` — React + TypeScript + Vite (mobile-first PWA для клиента; /business и /admin — кабинеты). Flutter SDK в среде недоступен, поэтому клиент — веб.
- Локально: Postgres на localhost:5432, БД `sulu`/`sulu_test`, пользователь `sulu`/`sulu` (только dev).
